# KUKİ: Eto'ya Karşı

Islık çalarak uç, kantin engellerini aş, sonra **Şaşı Sultan Eto**'ya laf fırlatarak onu yen!

## Nasıl oynanır
- **Dokun / Tıkla / Boşluk** → Kuki kanat çırpar (ve ıslık çalar)
- 12 engeli geçince **boss savaşı** başlar: her dokunuşta Kuki uçar **ve laf fırlatır** (ZAM!, İZİN!, MOLA!…)
- Eto'nun canı yarıya inince **Yavuz, Efe ve Sıraç** destek olarak gelir ve hep birlikte **ULTİ: TOPLU DİLEKÇE** atar (savaş başına bir kez)
- Arada uçan **çay molası** bardağını yakala, 1 can kazan
- Eto'nun **terliklerinden** ve **şaşı lazerinden** (kırmızı ✕ işaretine dikkat!) kaç
- **P / Esc** duraklat · **M** sesi kapat

## GitHub Pages'e yükleme (tarayıcıdan, kurulum gerekmez)
1. github.com'da **New repository** → isim: `kuki-vs-eto` → **Public** → Create.
2. **uploading an existing file** linkine tıkla, bu klasörün **içindeki her şeyi** (index.html, game.js, style.css, assets klasörü, .nojekyll) sürükle bırak → **Commit changes**.
3. Repo'da **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
4. 1-2 dakika sonra oyun şu adreste: `https://KULLANICI-ADIN.github.io/kuki-vs-eto/`

> Not: `index.html` dosyasını bilgisayarda çift tıklayarak açarsan ıslık sesi bazı tarayıcılarda gecikmeli çalabilir; GitHub Pages'te sorunsuz çalışır.

## Dosyalar
- `index.html` — ekranlar (menü, karakter seçimi, oyun sonu)
- `style.css` — arayüz tasarımı
- `game.js` — oyun motoru, karakter çizimleri, müzik
- `assets/islik.mp3` — zıplama ıslığı
